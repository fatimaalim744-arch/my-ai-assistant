# My AI Assistant

A simple AI chatbot built with Python and Mistral.

## How to Use

1. Install Python
2. Install Ollama from ollama.ai
3. Run: `ollama pull mistral`
4. Install dependencies: `pip install requests flask sqlite3`
5. Run: `python app.py`
6. Open: http://localhost:5000

## Features

- Chat with AI
- Saves conversations
- Clean web interface
